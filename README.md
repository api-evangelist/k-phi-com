K-φ (K-Phi) provides an FP&A and treasury platform for small and mid-sized companies, offering integrated financial statements, budgeting, cash forecasting, bank feeds, and invoice management. The service includes a Builder pass allowing custom AI-driven extensions via Claude, Codex, or Gemini CLI. It supports connections to major ERPs like SAP, Oracle, NetSuite, QuickBooks, and Xero, and offers a unified API for data access and automation.

**Areas:** Finance · FP&A · Treasury · API · SaaS
